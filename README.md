# Houzing — Real Estate Landing

Верстка лендинга по макету Real Estate Website (Community) / Houzing.

## Стек

- Pug
- SCSS
- JavaScript
- Bootstrap 5
- Webpack

## Команды

```bash
npm install
npm run dev    # http://localhost:4300
npm run build
```

**Секции:** header, hero с параллаксом, search bar, about, services, featured listings (фильтр), why choose us, cities/rentals/testimonials/agents (карусели), blog, CTA, footer.

**Эффекты:** scroll fade-in, parallax на hero/about/CTA, карусели со свайпом, sticky header, мобильное меню.
